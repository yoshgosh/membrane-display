# Membrane Display

画面を長押しすると凹むような擬似触覚エフェクトを追加する Chrome 拡張機能。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダを選択

## 使い方

1. ツールバーのアイコンをクリックしてポップアップを開く
2. ボタンで **エフェクト ON / OFF** を切り替える
3. ON の状態で任意の Web ページ上を**長押し**するとメンブレン（凹み）エフェクトが発動

設定はブラウザ全体で同期され、ページをリロードしても維持される。

## 動作要件

- Chrome (Manifest V3 対応)
- 対象: `http://` および `https://` の全ページ
